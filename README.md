# Harfix

oʻ → ö, gʻ → ğ, sh → ş, ch → ç. Lotin va kirill matnni qabul qiladi.

| `android/` | Android ilova va Harfix klaviaturasi ([android/README.md](android/README.md)) |
| `desktop/` | (keyin) Windows ilova |
